Light on your PC

Frames go straight to your GPU's encoder (AV1, HEVC or H.264). When no game runs, Replay sleeps.

Four keys to know

Change any of them in Settings.

Save a replay of the game in frontAlt F10
Save every gameAlt Shift F10
Start or stop a session recordingAlt F9
Mark the app in front as a gameCtrl Alt F10

Good to know

Windows SmartScreen warns on first start

Replay is not code-signed yet. Choose More info, then Run anyway.

The NVIDIA app also uses Alt+F10

Turn off Instant Replay in the NVIDIA app, or pick other keys in Replay. Running both records everything twice.

Updates and privacy

Replay checks GitHub once a day and installs updates only with a valid signature. It sends no data about you, and contacts an upload service only when you upload.

Check a download

Every release has SHA256SUMS.txt, signed with the key in the repository:

minisign -Vm SHA256SUMS.txt -P RWScCVL9ehOESIIXybJ0DWwRO1Y3O43uZSFI37/rYhyCrHMmNFmAjjNG
System requirements

Windows 10 (2004) or 11 and a GPU with a hardware video encoder. AV1 needs an NVIDIA RTX 40, AMD RX 7000 or Intel Arc GPU, or newer. macOS and Linux versions are in progress.
