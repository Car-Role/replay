Save the play after it happens.

Replay keeps the last minutes of every game in memory, encoded by your graphics card. Press Alt+F10 and the clip is saved. Trim it, mix the audio and share it in seconds.

Drag the handles and the preview shows that exact frame. Saving copies the video, so it takes seconds and loses no quality.

Built to stay out of your frame rate

Frames go from the game to your GPU's video encoder without passing through the CPU. When no game runs, Replay sleeps.

IDLE

0 ms

CPU time over 30 seconds with no game running, and about 3 MB of memory.

RECORDING

~5%

Of one CPU core while recording 1080p60 with game audio and mic.

SAVING

< 0.5 s

To write a two-minute clip. The buffer is never copied.

Every game, found by itself

Steam, Epic, Battle.net, Riot, GOG, EA, Ubisoft and Jagex launchers, game folders, the Windows Game Bar list and fullscreen 3D apps. Turn any game off on the Games page.

Several games at once

Each game has its own buffer. One hotkey saves the game in front, another saves all of them.

Your voice on its own track

Only the game's sound (not Discord or music), your mic, and a mix of both for players that play one track.

AV1, HEVC or H.264

NVENC on NVIDIA cards, and the hardware encoders on AMD and Intel. Up to 240 fps.

Trim, join and remix

A filmstrip trim bar that scrubs the preview, joins without re-encoding, and separate game and mic volume.

Share in one click

Copy the file and paste it into Discord, or upload it to Streamable and get the link copied.

Three steps

No account and no setup.

01

Install

Run the installer. It needs no admin rights and puts Replay in the notification area.

02

Play

Start any game. The icon turns red when Replay is recording it.

03

Press Alt+F10

The last two minutes are saved to Videos\Replay. Click the notice to trim and share.

Good to know

Windows SmartScreen

Replay is not code-signed yet, so Windows may warn the first time. Choose More info, then Run anyway.

The NVIDIA app uses Alt+F10 too

Turn off Instant Replay in the NVIDIA app, or pick other keys in Replay's settings. Running both records everything twice.

Updates

Replay checks GitHub once a day, downloads new versions in the background and installs them when you choose. Each update must carry a valid signature from the release key, or it is not installed.

Privacy

Replay sends no data about you. It contacts GitHub only to check for updates (you can turn this off), and Streamable only when you upload.

Check a download

Every release has SHA256SUMS.txt, signed with the key in the repository:
